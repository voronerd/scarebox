# SFX sources

All seven stings below are generated by `scripts/make_sfx.py` (numpy + scipy only: filtered
noise, synthesised tones, no real recordings of people or places). They are **CC0 by
construction** -- there is no underlying copyrighted recording to license, so there is no
Freesound page, author or licence to cite. Deterministic (fixed seed `20261015`), 48kHz mono
16-bit, each trimmed to <= 1.5s and loudness-normalised to -18 LUFS.
